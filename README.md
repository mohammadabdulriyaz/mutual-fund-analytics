# Mutual Fund Analytics - Capstone Project

## Project Overview
This project analyzes mutual fund performance using Python, SQL, and Power BI as part of the Data Analyst Internship at Bluestock Fintech.

## Technologies Used
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- SQLite for database
- Jupyter Notebooks for analysis
- Power BI for visualization

## Project Structure
- **Source Code**: All Python scripts and Jupyter notebooks
- **Datasets**: Raw and processed data files
- **Documentation**: Project documentation and schema
- **PPT/Slides**: Final presentation
- **Demo Video**: Project demonstration

## Key Features
1. ETL Pipeline for investor transaction data
2. Exploratory Data Analysis (EDA)
3. Fund Performance Analytics
4. Interactive Power BI Dashboard
5. SQL Database Design

## How to Run
1. Run `load_to_sqlite.py` to set up database
2. Run `clean_investor_transactions.py` for data cleaning
3. Open and run Jupyter notebooks for analysis
